# 🤖 Titko Bot – AI Streamer Desktop Application

*A desktop AI streamer application designed to interact with viewers, process conversations, and provide an intelligent streaming companion.*

---

## 📖 Overview

Titko Bot is an AI-powered desktop application built for live streaming. It serves as a virtual assistant and on-stream personality capable of responding to chat, processing AI conversations, and integrating with modern cloud services. The desktop application communicates with a backend service that handles AI processing, voice synthesis, and infrastructure.

---

## ✨ Features

* 🤖 AI-powered conversations
* 🎙️ Real-time voice responses
* 💬 Live chat interaction
* 🖥️ Desktop application interface
* ⚡ Backend API communication
* ☁️ Cloud-ready architecture
* 📦 Docker container support
* 🔒 Scalable backend services

---

## 🏗️ Architecture

The project consists of two main components:

### 🖥️ Frontend

The desktop application is responsible for:

* User interface
* Sending requests to the backend
* Displaying AI responses
* Managing application state

**Built with:**

* JavaScript
* Neutralino.js (Nano Desktop Framework)

---

### ⚙️ Backend

The backend powers all AI functionality and services, including:

* AI request processing
* Voice generation
* API integrations
* Authentication
* Business logic
* Cloud deployment

**Built with:**

* JavaScript (Node.js)
* ElevenLabs AI
* Docker
* Microsoft Azure
